Architecture for Adversarial Conversational Debate
mermaid
graph TD
    START([User Query / FIR Document]) --> EA[Evidence Analyzer]
    EA --> LG[LexiGraph Law & Knowledge Retrieval]
    LG --> InitState[Initialize Debate Context]
    
    InitState --> Pros[Prosecutor Agent]
    Pros --> Def[Opponent Defense Agent]
    Def --> Judge[Judge Agent / Score & Evaluate]
    
    Judge -- "Round < Max & Arguments Evolving" --> Pros
    Judge -- "Final Round / Decision Ready" --> Verdict[Judge Verdict]
    Verdict --> END([Final Judgment & Transcript])
Core Steps to Implement the Conversational Debate Loop
1. Define the Conversation & Debate State
In your AgentState configuration, track the conversation history and turn counter:

python
class AgentState(TypedDict):
    session_id: str
    user_query: str
    structured_facts: dict
    lexigraph_result: dict
    
    # Adversarial Debate State
    debate_turns: List[dict]    # List of {"speaker": "prosecutor"|"defense", "text": "...", "round": 1}
    prosecution_args: str       # Latest prosecution argument
    defense_args: str           # Latest defense counter-argument
    
    debate_round: int           # Current round index
    max_rounds: int             # e.g., 3 rounds of back-and-forth debate
2. Implement Rebuttal Memory in Prosecution & Defense Agents
For true adversarial debate, each agent must receive the entire previous dialogue history plus the opponent’s latest argument:

Prosecutor Agent (Turn $N$): Inputs: structured_facts, lexigraph_result, defense_args (Opponent's previous rebuttal), debate_turns. Prompt instructions: "Analyze the defense's latest counter-argument. Refute their claims using evidence and relevant sections, then reinforce the prosecution's charges."

Defense Agent (Turn $N$): Inputs: structured_facts, lexigraph_result, prosecution_args (Opponent's argument), debate_turns. Prompt instructions: "Analyze the prosecution's latest accusation. Identify legal loopholes or missing evidence, counter their claims, and defend the accused."

3. Setup LangGraph Loop Condition
In 

orchestrator_graph.py
, configure sequential turns and a conditional edge based on debate_round:

python
def should_continue_debate(state: AgentState) -> str:
    current_round = state.get("debate_round", 0)
    max_rounds = state.get("max_rounds", 3)
    
    if current_round < max_rounds:
        return "continue_debate"
    return "render_verdict"
# Edges:
# START -> evidence_analyzer -> lexigraph -> prosecutor -> defense -> judge_score
# judge_score --(should_continue_debate)--> "continue_debate": prosecutor
#                                       --> "render_verdict": judge_verdict -> END
